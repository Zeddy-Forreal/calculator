# 🧮 Calculator App

A clean and functional calculator built with HTML, CSS, and JavaScript. Supports typing, keyboard input, and instant calculation using the Enter key.

## 🌟 Features

- 🟰  Basic arithmetic operations: ➕➖✖️➗
- 🔢 Support for parentheses and decimal points  
- ⌨️ Keyboard input support for numbers and operators  
- ✅ Automatically evaluates expression on Enter key  
- 🧹 Clear button to reset the current calculation  
- 🎨 Clean and responsive design  

## 🧰 Tech Stack

- HTML  
- CSS  
- Vanilla JavaScript
